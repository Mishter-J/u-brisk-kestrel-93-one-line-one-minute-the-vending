A program that writes one pickup line, spoken by a vending machine to a passing human, to `/output/entry.txt` — for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty. The line was picked from twelve candidates scored against the judge brief itself: first-person machine voice, the machine's own world (a bill validator that rejects crumpled bills, exact change), and the punch landing in the last few words — the machine that demands exact change from everyone waives it for you.

## Run it

```sh
python3 main.py
```
